# 🎴 Tp API TCG - Pokémon

## 📖 Description

Application web de gestion de cartes Pokémon.
Le projet permet de créer une collection de cartes, vendre ses doublons, et ouvrir un booster toutes les 5 minutes.
Ce projet a été réalisé dans le cadre du cours *API (ExpressJS)*.


## 🚀 Fonctionnalités

* [x] Création et gestion d’une collection de cartes Pokémon
* [x] Ouverture automatique de boosters toutes les 5 minutes

## 🛠️ Technologies utilisées

* **Front-end** : PHP, Bootstrap
* **Back-end** : Node.js, ExpressJS
* **Autres** : img.pokemondb.net

## ⚙️ Installation & utilisation

### 1. Cloner le projet

```bash
git clone https://github.com/MarineG404/api_express/
cd tp-api-tcg
```

### 2. Installer les dépendances (API)

```bash
cd api
npm install
```

### 3. Lancer le projet

Dans le dossier **API** :

```bash
node app.js
```

Dans le dossier **front** :

```bash
php -S localhost:8000
```
